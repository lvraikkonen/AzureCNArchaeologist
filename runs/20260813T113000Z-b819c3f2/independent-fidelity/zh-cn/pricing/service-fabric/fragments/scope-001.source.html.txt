<h3>
                                    Azure 上的 Service Fabric
                                </h3>
<p>
                                    Service Fabric 可用于任何标准大小的 Windows Server 虚拟机或 Linux 虚拟机（Linux 上的 Service Fabric
                                    目前只提供预览版）。Service Fabric 在预览版下也可用，同时在 Azure 上运行 Ubuntu 映像。仅针对你选择的计算实例以及用于创建 Service
                                    Fabric 群集的存储和网络资源向你收费。对 Service Fabric 服务本身不收取任何费用。有关必需资源的价格的详细信息，请访问以下页面：
                                </p>
