# ACNArchaeologist 内容重建

本词汇表定义从 Azure 中国区上游 HTML 到 CMS 交付包这一过程中的统一语言。它只定义项目概念，不描述代码结构或具体算法。

## 输入与范围

**产品标识（Product Key）**:
一个定价页或支持文章在本项目中的稳定名称，用来关联产品配置、双语 HTML 和输出。
_Avoid_: 产品名称、文件名、Slug

**参考产品配置（Reference Product Definition）**:
从冻结项目复制来的产品说明，可用于参考页面类型、Category、双语源路径和历史 Strategy；其中旧 `capability_status` 不代表新项目的支持结论。
_Avoid_: 已验证产品配置、支持证明

**新项目支持状态**:
新实现依据真实双语输入、机器检查和验收结果对一个产品作出的支持、阻断或待确认结论。
_Avoid_: 旧 `capability_status`、历史成功状态

**产品 Category**:
用于选择一组定价产品进行处理的业务分类；它不改变产品的源路径或 Payload 路径。
_Avoid_: 文件夹类型、Strategy

**上游输入快照**:
上游团队一次性交付的中英文 HTML 与可信 `soft-category.json` 集合，是一次增量变化识别的完整输入。
_Avoid_: 上游 HTML 快照、实时网页、已经固定的批次输入

**对比基准**:
上一次已经固定的新旧比较依据，包括 Frozen HTML、可信配置和产品配置投影；它不代表相同内容已经交付。
_Avoid_: 最近 Release、当前 Batch、历史摘要

**Git 文件比较**:
用 `git diff --no-index` 直接比较两个指定文件是否相同；它不要求文件属于 Git 仓库，也不创建提交或保存文件摘要。
_Avoid_: Git 提交比较、内容摘要、变化报告

**Frozen HTML**:
从上游 HTML 快照中按参考产品配置定位并固定下来的双语 HTML，是一次处理使用的源内容依据。
_Avoid_: 清洗后的 HTML、修复后的 HTML、实时网页

**Batch 固定输入**:
为一个 Batch 单独保留且不再变化的双语 HTML、可信配置和相关产品配置，是抽取、机器检查、恢复和人工审核共同使用的输入依据。
_Avoid_: 可变的上游输入快照、最近 Release

**`soft-category.json`**:
上游提供的可信映射，用于补充源 HTML 中无法直接表达的状态与价格表对应关系；它不能替代 Frozen HTML 中的实际内容。
_Avoid_: 第二份源页面、推测规则

**配置实际使用证据**:
生产抽取处理一个产品时真实查询过的 `soft-category.json` 的 `(os, region)`、该行是否存在和返回表格名称。它用于把后续配置变化关联到实际消费者。
_Avoid_: 全配置复制、推测依赖、编码身份

**处理项**:
一个产品与一种语言组成的最小抽取和机器检查单位。
_Avoid_: 产品、文件、Batch

**双语产品处理**:
把同一产品的 `zh-cn` 和 `en-us` 两个处理项作为一个不可拆分的运行范围；任一语言变化都重新处理两种语言。
_Avoid_: 单语言增量产品

## 抽取与结果

**Strategy**:
根据页面结构从 Frozen HTML 中选择并组织业务内容的一类抽取规则。
_Avoid_: Product Key、文件大小模式、验证规则

**Business Payload**:
准备交给 CMS 的产品 JSON，只包含 CMS 需要的业务字段，不包含日志、错误、审核记录或运行时间。
_Avoid_: 机器检查报告、运行记录、交付包

**内容组（Content Group）**:
定价 Payload 中与一个源页面可选状态对应的 HTML 内容及其筛选条件。
_Avoid_: 任意 HTML 片段、Category

**页面状态**:
用户能通过源页面现有区域、软件或 Category 控件实际选择的一种内容组合。程序不能把控件中不存在的理论组合当成页面状态。
_Avoid_: 组合公式、推测状态

**共享定价内容（`sharedContent`）**:
Complex 定价页中属于某个区域、但由这个区域下所有 Category 共用的源 HTML。它必须有独立、可证明的源边界，并在每个对应 Content Group 中完整核对。
_Avoid_: `baseContent`、复制任意相邻片段、公共区块

**源片段**:
从 Frozen HTML 中确定边界并与某个 Payload HTML 字段对应的内容。
_Avoid_: 整个页面、Strategy 输出

**HTML 规范化**:
对源片段和 Payload 片段使用的同一套最小格式整理规则，使无业务意义的排版差异不妨碍内容核对。
_Avoid_: HTML 修复、内容删除、宽松清洗

## 机器检查与人工审核

**重复抽取检查（L3a）**:
在相同输入和代码下再次抽取，并确认完整 Business Payload 与第一次结果一致；它证明结果稳定，但不证明内容选对了。
_Avoid_: 内容准确性检查、恢复测试

**源内容核对（L3b）**:
不依赖生产 Strategy 的内容选择过程，独立定位源片段并与 Payload 对应 HTML 核对；它证明 Payload 与 Frozen HTML 一致，但不证明上游内容本身正确。
_Avoid_: 第二个完整抽取器、人工批准、上游事实审核

**独立源片段定位**:
仅依据 Frozen HTML、参考产品配置和必要的 `soft-category.json` 找到待核对源片段的过程，不复用生产 Strategy 的状态映射或内容选择结果。
_Avoid_: Strategy 重跑、从 Payload 反推源内容

**明确停止处理**:
源边界、配置名称或状态对应关系无法唯一证明时，把处理项记为失败或阻断并说明直接原因。它不是容错失败，而是防止猜测进入 Payload 的正常保护行为。
_Avoid_: 选择第一个候选、宽松回退、静默跳过

**人工审核**:
由真实审核人查看 Frozen HTML、Payload 和机器检查差异后作出的批准或拒绝决定。
_Avoid_: 机器检查、自动批准

**审核清单（Review Queue）**:
从一个已封存 Batch 中列出所有抽取、L3a、L3b 均通过处理项的只写一次清单，并直接指向审核材料。它不包含人工结论。
_Avoid_: 自动批准列表、失败项补录入口

**审核决定（Review Decision）**:
真实审核人对一个完整双语产品作出的批准或拒绝记录，包含审核人、实际检查范围和说明。同一审核 ID 下不能覆盖已有决定。
_Avoid_: 单语言批准、机器生成身份、修改旧决定

**人工审核台**:
只在审核人电脑上运行的页面。它按产品展示中文和英文，把 L3b 独立确定的 Frozen HTML 源片段与 Payload 对应字段并排显示，并提交真实人工决定。页面不能调用生产 Strategy 来确定源片段，也不能自动批准。
_Avoid_: 自动验收页面、Strategy 预览器、单语言审核表单、Review Workbench 黑盒

**本地审核服务**:
只绑定 `127.0.0.1`、只接受指定人工审核台访问的 Python 服务。它读取审核清单和材料，并把页面提交交给不可覆盖的审核决定服务。临时令牌仅用于限制本机页面访问，不代表内容身份或验证证据。
_Avoid_: 公网审核 API、Next.js 写接口、内容摘要服务、生产发布接口

**只写一次**:
文件或目录一旦以正式 ID 创建，就不能用相同 ID 替换内容；修正时使用新的审核 ID 或 Release ID。
_Avoid_: 先覆盖再备份、原地修补历史记录

## 批次与交付

**Batch**:
对一个明确产品范围执行 Frozen HTML 固定、抽取、两项机器检查和审核准备的一次运行。
_Avoid_: 单个处理项、交付包

**受影响产品**:
上游新快照或其可信配置发生变化后，需要重新处理中文和英文的产品。
_Avoid_: 只变化的单语言文件、整个产品全集

**增量 Batch**:
只包含受影响产品、但仍对每个产品执行完整双语流程的 Batch。
_Avoid_: 跳过机器检查的快速抽取、单语言 Batch

**未解决受影响产品**:
已被变化识别选中，但尚未完成双语交付，或尚未由审核人明确结束而不交付的产品；更新对比基准不能使它自动消失。
_Avoid_: 已忽略产品、下一次重新检测项

**重新处理记录**:
未解决产品在程序修正后，复用原增量 Batch 固定输入而新增的一次完整双语处理结果；它属于原增量 Batch，并保留此前结果和审核决定不被覆盖。
_Avoid_: 覆盖重跑、新增变化 Batch、修改旧 Payload

**结束而不交付**:
审核人明确确认某个受影响产品本次不进入交付包，并提供可读原因的终结决定；普通拒绝本身不等同于该决定。
_Avoid_: 自动忽略、审核拒绝、机器阻断

**交付包（Release）**:
由同一审核会话中当前全部有效批准双语产品的 Payload 组成、创建后不允许覆盖的 CMS 交付目录。
_Avoid_: 普通输出目录、Batch、上传动作

**增量交付包（Delta Release）**:
只包含某次增量 Batch 中获批准的受影响产品双语 Payload 的交付包。
_Avoid_: 任意挑选部分文件的 Release、未审核差异包
