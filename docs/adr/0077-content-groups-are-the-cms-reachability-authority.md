# Content Groups Are the CMS Reachability Authority

Status: Accepted

CMS import reads the Business Payload's exact `contentGroups` as the states it may render and does not derive a Cartesian product from `filterDefinitions`. Each group therefore represents one source-proven reachable tuple, carries complete single-value machine criteria, and uses a Structured Content Group Name whose localized path segments are joined by the exact ` - ` delimiter in `region`, `software`, `category` order with absent path dimensions omitted. Treating `groupName` as free-form display text or manufacturing groups for theoretical option combinations was rejected because both would change the CMS-imported state machine.
