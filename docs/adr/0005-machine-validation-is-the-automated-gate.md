# Machine Validation Is the Automated Gate

Status: Accepted

The existing Machine Validation result remains the single automated gate for a Business Payload rather than adding an independent quality state. Contract Validation and Content Quality remain distinct evidence within that judgment: a blocking contract or content-quality error fails Machine Validation, while an observational Quality Finding remains a warning; human rejection remains a separate Review outcome. A second quality state was rejected because it would add another lifecycle axis without representing a distinct authorization decision.
