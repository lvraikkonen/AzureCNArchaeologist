# v0.4 Visual Review Is Desktop-only

Status: Accepted

Complex Table Visual Review in v0.4 evaluates Visual Semantic Equivalence only under a frozen desktop Rendering Profile. Mobile and other responsive viewports are outside the validation and approval guarantee and must be reported explicitly as not validated rather than implicitly passing; adding them requires a later versioned profile and fresh applicable review evidence. Requiring mobile coverage in v0.4 was rejected to keep the archaeology and pricing-fidelity milestone focused on the agreed desktop consumption path.
