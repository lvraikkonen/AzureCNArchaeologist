# Block Language Mapping Errors but Report Upstream Language Findings

Status: Accepted

A contradiction among Product Definition language, capture evidence, Source Location, Normalized Input path or hash, and Business Payload language is a blocking Input Language Mapping Error. When those mappings are correct but the captured upstream route itself serves the wrong language or conflicting HTML language metadata, the issue is an Upstream Language Finding: faithful reconstruction may pass Machine Validation, but approval remains blocked until disposition. Statistical text-language detection is retained only as supporting evidence because bilingual product names, SKUs, and technical vocabulary make it unsuitable as an independent gate.
