# Allow Only Region-Projected Shared Content

Databricks proves that CMS `sharedContent` is not uniformly legacy: price-bearing content before its Category panels is shared by all descendant Categories but must first be projected through the active Region and frozen `soft-category.json` rules. We therefore allow `sharedContent` only when source ancestor identity, descendant Category scope, applicability-config identity, and the exact per-Region projection are independently frozen and replayed. Table IDs used as applicability identity must be globally unique in the source page, and a retained shared table identity may appear only in the applicable states' `sharedContent`, never in `content`, `baseContent`, or `commonSections`; partial as well as complete copies are blocking leakage. Arbitrary legacy shared fragments, page-global promotion, unfiltered copying, and cross-Region reuse remain forbidden. Software-scoped Prefix Content stays a separate unchanged projection into `content`.
