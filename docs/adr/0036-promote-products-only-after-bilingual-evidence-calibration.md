# Promote Products Only after Bilingual Evidence Calibration

Status: Accepted

Expanded Matrix Promotion requires both languages to pass Product Definition, input, and CMS contract checks; two clean runs under identical inputs and Validation Profile must produce identical business-content and fact-evidence hashes; Curated Baselines and all applicable Interaction Baselines and Complex Table Visual Reviews must be human-reviewed; and unit, component, and end-to-end tests must be committed with no unclassified or blocking finding. Stable Source Quality Findings may remain expected warnings because matrix promotion expands reconstruction regression coverage and does not grant publication approval. Promotion after one green run was rejected because nondeterminism, incomplete state coverage, or an unreviewed expectation could otherwise become a permanent committed test oracle.
