# Quarantine Unvalidated Experimental Extractions

Status: Accepted

Offline research may use a dedicated `experimental-extract` lane to force a named Semantic Extraction Strategy for an explicitly requested `known_unsupported` item, but formal `extract` and pipeline commands receive no generic validation-bypass flag. The command's only authority is the closed-world `data/configs/experimental-extraction-exceptions.json`; each entry pins Product Key, languages, forced strategy, Product Definition-resolved source paths, per-language SHA-256, reason, owning team, maximum input bytes, timeout, peak RSS, output root, and expiry. The v0.4 `virtual-machines` entry reads its exact `data/current_prod_html` sources directly without creating canonical Normalized Inputs, pins `zh-cn` as 8,064,052 bytes / `b1eedddb9020c94399063f95cc746609c1c86ec658fba5457d8d84197a2ea19f` and `en-us` as 7,239,577 bytes / `8d0167fe4aa7e196b1879941d6830b3ef30f7e448501e53706823d736e827ea1`, allows 8 MiB, 900 seconds and 2 GiB RSS, and writes beneath gitignored `output/experiments/{experiment_id}/{language}/`. Any mismatch fails before extraction. The lane emits an Experimental Payload Candidate plus success manifest with `trust_status=unvalidated`, `approval_eligible=false`, and `publishable=false`; exit `0` only means both were completely generated and is never printed as `PASS`. Failure returns `1`, removes partial Candidate files, and writes only internal diagnostics. Artifacts cannot enter canonical Batch outputs, Review Queue, baselines, upload, or publication. `zh-cn` is delivered first, and P0 completes only after both languages produce their candidate and manifest; failure blocks P0, while independent foundation work may continue. The exception expires on source-hash change or v0.4 completion and never changes support qualification.
