# Detect Duplicates Relative to Source Multiplicity

Status: Accepted

Duplicate content and cross-state leakage are evaluated relative to the Expected state-scoped multiset and Pricing Fact Applicability. Equal content or prices in multiple source-authorized regions, tabs, or repeated source occurrences remain faithful independent observations; an unexplained same-state source repetition may separately become a Source Quality Finding. Any payload occurrence beyond expected multiplicity or in a state without source authorization is blocking, while hash equality alone never proves duplication or leakage because legitimate regional prices can be identical.
