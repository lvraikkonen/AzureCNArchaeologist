# Preserve Source-confirmed Empty Selection States

Status: Accepted

When frozen Applicability Evidence proves that source configuration intentionally leaves an otherwise reachable state's full rendered content—its state-specific `content` plus any exact proven `sharedContent`—without an applicable price-bearing fragment, v0.4 preserves that Source-confirmed Empty Selection State as one active, non-placeholder `contentGroup` containing any remaining source content and records a Source Quality Finding. Empty Category-specific `content` is insufficient when price-bearing Region-Projected Shared Content remains applicable. Such a group may pass Machine Validation without invented pricing, but remains ineligible for approval until disposition; this exception requires the exact source state, excluded fragment identities, configuration path, and configuration hash, and can never be inferred from an extractor's empty result. A language-neutral exclusion configuration confirmed to govern both languages may use the same configuration identity for `zh-cn` and `en-us`, but each language must independently bind that configuration to the applicable fragment identities in its own frozen Source Snapshot. Dropping the state would violate the source-proven Reachability Relation, while inventing or retaining excluded prices would violate faithful reconstruction.
