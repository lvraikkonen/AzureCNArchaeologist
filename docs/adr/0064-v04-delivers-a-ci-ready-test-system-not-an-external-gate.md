# v0.4 Delivers a CI-ready Test System, Not an External Gate

Status: Accepted

v0.4 delivers runner-agnostic pytest commands, the Deterministic and Live Interaction Reference Suites, and Core and Expanded strategy matrices with reproducible fixtures and reports. It does not add GitHub Actions, required branch checks, or claim that an external automation platform currently blocks merges; roadmap and completion language must say CI-ready test system until a platform is selected and configured separately. Keeping an unspecified “CI gate” promise was rejected because local test capability and enforced repository governance are materially different outcomes.
