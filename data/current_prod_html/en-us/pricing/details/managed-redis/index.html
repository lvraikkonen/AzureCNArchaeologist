FAQ

Expand All
  • How is Azure Managed Redis priced?

    Azure Managed Redis offers multiple SKUs with various memory and compute (vCPU) options, making it easy to find a solution that fits your use case and budget.

  • Are Redis modules included on all tiers?

    Redis modules can be utilized across nearly all tiers. Refer to the features table above for further details.

  • What is the SLA for Azure Managed Redis?

    Azure Managed Redis offers up to 99.99% uptime, which can increase up to 99.999% when the following criteria are met: (1) deployment across at least three Azure regions with three or more Availability Zones in each region, and (2) active geo-replication enabled for all cache instances.

  • What is Azure Managed Redis reserved instances (RI)?

    Save on Azure Managed Redis with a one- or three-year reservation. For more information, see documents pages.
