## 3. 生产 Page-Global Content contract

### 3.1 保持不变的 S1–S4

当前成功路径保持原义与优先级：

- S1：唯一、无 active controls 的 static formal selector；
- S2：direct price-bearing pricing-details section；
- S3：intrinsic unheaded simple pricing body；
- S4：direct pricing-heading range。

现有显式 boundary 值 `sole_static_formal_selector_before_common_sections` 与 `after_final_formal_selector_before_common_sections` 的 predicate、fragment composition、hash 和 wire behavior 均不改变。新规则只能由 Product Definition 显式选择，不能成为 intrinsic fallback。

### 3.2 S5：`sole_direct_static_business_wrapper_before_common_sections`

resolver 必须同时证明：

1. page-level `div.pure-content` 唯一；
2. 忽略 Comment、纯空白和 `script/style/template/tags` 后，恰有一个 unclassed direct material wrapper 位于 exact ProductDescription 与 exact FAQ/SLA common section 之间；
3. wrapper 不是 common section，也不含 common-section boundary；
4. wrapper 不含 formal selector、select/form/button、radio/checkbox、tab/tablist/radiogroup 或 region/software/category control；
5. 对 retained wrapper 自身及其 descendants，没有 `id` 属性的 element 可以保留；任何存在的 `id` 属性值都必须非空，且每个 ID 必须在整页 page-global unique；
6. Source fragment 精确为 `str(wrapper)`，`fragment_count=1`；
7. Source/Wire hashes 与 Product Definition 当前语言 identity 精确相等。

返回值只包含 `clean_html_content(str(wrapper))` 经既有 CSS generated semantics materialization 后的 wire body。不得按 wrapper 内 child 数、注释、heading 文本或产品名选择。

第 2 项的 ignore 规则只适用于 `pure-content` direct-sibling candidate scan：这些节点不被误判为第二个 material candidate。一旦 wrapper 被选中，Source fragment 仍精确等于 `str(wrapper)`；wrapper 内部或 fragment bytes 的任何变化继续受 frozen `source_html_sha256` / `wire_html_sha256` 约束，不因 scan ignore 获得豁免。

### 3.3 S6：`sole_inert_singleton_selector_target_before_common_sections`

resolver 必须同时证明：

1. 恰有一个 outermost formal selector，且是 `pure-content` 的 direct child；
2. desktop control domain 恰有一个 selected identity；mobile control domain 也恰有一个 selected identity；
3. 两套 presentation 独立解析后 identity 和 target ref 完全一致；
4. target ref 是合法 local fragment，整页恰有一个对应 element；
5. 该 target element 必须位于同一个 outermost formal selector 内，并且是该 selector 内唯一 material business target；
6. target 不得位于 selector 外部，不得通过跨 wrapper 或 global lookup 拼接正文；
7. formal selector 内不得存在第二 material target、region/category/software alternative 或其他 reachable dimension；
8. target 自身的 `id` 必须与 ref 精确相等；对 retained target 自身及其 descendants，任何存在的 `id` 属性值都必须非空，且每个 ID 必须在整页 page-global unique，包括不得与 selector UI 的 ID 碰撞；没有 `id` 属性的 descendant 可以保留；
9. formal selector 后首个 material sibling 是 exact FAQ/SLA common boundary；
10. Source fragment 精确为唯一 target 的 `str(Tag)`，`fragment_count=1`；
11. Source/Wire hashes 与 Product Definition 当前语言 identity 精确相等。

输出只含唯一 target wire body，不含 desktop/mobile labels、`select`、tab list 或 selector wrapper。`display:none`、DOM first、CSS class `active` 或单一 `data-href` 任一单独条件都不足以证明 singleton。

## 9. 暂停与停止条件

出现以下任一情况，停止实施并回到 plan review：

- Plan freeze 前后 inventory、canonical key、formal input/fragment/wire identity 或 capability 变化；
- S5 wrapper 不唯一、邻接 ownership 改变或需依赖 child 数/注释/文本；
- S6 出现第二 option/target、desktop/mobile disagreement、active dimension、selector 外 target、整页唯一但不属于该 selector 的 target，或跨 ownership boundary 拼接；
- S5/S6 retained wrapper/target 或 descendants 出现 empty/duplicate/colliding ID，且继续实施需要删除、重命名、ordered-unique 或 first-match Source nodes；
- 修复要求扩大到 S1–S4、inventory 外 products 或旧 handoff deferred items；
- Product Definition 需要新对象形状、selector DSL 或全 catalog schema migration；
- 旧 Profile/Evidence 1.1 必须改语义/bytes，或 production/L3b 必须共享 helper；
- target routing 需要 persisted registry、registry Schema/service、dynamic discovery 或 compatibility facade 才能继续；
- fixed-input 319 payload 中任一出现未解释 byte delta；
- `virtual-wan` blocker 或 `event-grid` exclusion 被顺带改变；
- formal Batch membership/denominator 缩小，或四 repair items 之外出现未解释 status/error/payload delta；
- 新 Batch provenance 未同时绑定第 4.2 节四个 required artifacts，或 repair/witness 发生 stale、missing、ambiguous、inferred、跨 target set/跨 Profile binding；
- repair/witness 任一 Evidence failed/blocked/fatal/stale/corrupt/identity drift；
- historical v0.5.3/v0.5.4 Evidence 不再满足第 7.3/7.4 节，或 P6 v0.5.5 current Evidence 不再精确匹配 P5 人工接受对象；
- formal producer 不是 committed clean HEAD，完整门禁失败；
